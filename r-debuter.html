Débuter en R

Comment le Codex R exécute votre code et vérifie votre réponse

Le Codex R exécute R dans votre navigateur. Il n'y a rien à installer : la page remplace RStudio pour s'entraîner.

Chaque question demande d'écrire quelques lignes de R. Vous les exécutez pour voir le résultat, puis vous demandez la vérification : le Codex compare votre résultat à la réponse attendue.

1. L'écran d'une question

Une question tient sur un écran, en quatre zones. Chaque zone défile pour elle-même.

1. Énoncé

La question, puis l'indice et la solution, repliés. La solution s'ouvre après une première exécution.

2. Éditeur

Votre code R. « Effacer » revient au point de départ.

3. Données et vérification

Le tableau en mémoire et ses colonnes. « Exécuter » et « Vérifier ma réponse ».

4. Console

Ce que R affiche, les messages d'erreur, et le graphique produit.

  • ☰ Questions ouvre la liste, avec ses filtres : chapitre, jeu de données, notion. Précédente et Suivante parcourent cette liste.
  • Ctrl+Entrée, dans l'éditeur, exécute le code.
  • Votre progression est gardée dans ce navigateur. « Sauvegarder ma progression » l'emporte dans un fichier.

2. Exécuter, puis vérifier

  • Exécuter lance votre code et affiche dans la console ce que R écrit, comme dans RStudio.
  • Vérifier ma réponse compare votre résultat à celui de la solution. Selon la question, le Codex compare :
Ce qui est comparéCe qu'il faut écrire
La valeur calculéeLa dernière ligne de votre code donne la réponse : surface * dose, ou le nom de l'objet qui la contient.
Ce que le code affichePour str(), summary() ou print() : l'affichage doit être le même que celui de la solution.
Un graphiqueLa bonne fonction (hist(), boxplot()…) doit produire un tracé. Le tracé attendu s'affiche à côté du vôtre : comparez titre, axes et forme.

Deux valeurs numériques sont égales à la précision près : 0.1 + 0.2 et 0.3 sont jugés identiques.

3. Les données

Les questions portent sur trois tableaux de données, déjà en mémoire. Il n'y a rien à charger : utilisez directement leur nom.

La zone « Données et vérification » montre la structure du tableau, comme str() : ses colonnes, leur type, leurs premières valeurs.

Les questions du chapitre I, « Importer des données », lisent un fichier CSV déjà déposé dans le dossier de travail : read.csv("parcelles.csv").

4. Les règles de R qui reviennent le plus

  • <- range une valeur dans un objet : surface <- 7.1.
  • Le séparateur décimal est le point : 7.1. c(7,1) est un vecteur de deux valeurs.
  • R distingue majuscules et minuscules : Note et note sont deux objets différents.
  • Une colonne d'un tableau se lit avec $ : parcelles$Rendement_qx.
  • Un texte s'écrit entre guillemets : "Blé". Sans guillemets, R cherche un objet de ce nom.

5. Le bac à sable

Le bac à sable, sur l'accueil du Codex R, est un éditeur libre : pas d'énoncé, pas de vérification. On y choisit l'un des trois tableaux, ou on importe son propre fichier CSV avec « Importer un jeu de données ». Le fichier se lit ensuite par son nom : donnees <- read.csv2("mes_donnees.csv"). Il reste disponible jusqu'au rechargement de la page.
