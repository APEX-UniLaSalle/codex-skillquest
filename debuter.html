Débuter : lire avec input(), afficher avec print()

Comment un programme du Codex reçoit ses données et rend son résultat

📄 Cheat Sheet Python

Chaque exercice donne des jeux d'essai : une entrée et une sortie attendue.

L'entrée est une suite de lignes de texte. Votre programme les lit une par une avec input(), calcule, puis affiche le résultat avec print().

Le Codex compare ce que votre programme affiche à la sortie attendue. Le jeu d'essai passe si les deux sont identiques.

Entrée du jeu d'essai

6
4

Votre programme

longueur = int(input())  # lit la ligne 1 : 6
largeur = int(input())   # lit la ligne 2 : 4
print(longueur * largeur)

Sortie comparée

24

1. Lire une ligne : input()

  • Chaque appel à input() lit la ligne suivante de l'entrée.
  • Le premier input() lit la ligne 1, le deuxième la ligne 2, et ainsi de suite.
  • input() rend toujours du texte, même si la ligne contient un nombre.
  • Pour calculer, convertissez : int(input()) pour un entier, float(input()) pour un décimal.
  • Une ligne de mots reste du texte : mot = input().

2. L'amorce et le tableau des jeux d'essai

À l'ouverture d'un exercice, l'éditeur contient déjà les lignes de lecture : c'est l'amorce. Les noms des variables sont choisis pour l'exercice.

Dans le tableau des jeux d'essai, chaque ligne d'entrée porte le nom de la variable qui la reçoit :

VariableLigne d'entrée
longueur6
largeur4

La mention à lire désigne une ligne que l'amorce ne lit pas. Votre programme la lit lui-même, en général dans une boucle.

3. Plusieurs valeurs sur une même ligne

split() découpe la ligne aux espaces et rend une liste de textes.

Entrée

6 4

Programme

morceaux = input().split()  # ['6', '4']
longueur = int(morceaux[0])
largeur = int(morceaux[1])
print(longueur * largeur)   # 24

4. Un nombre de lignes annoncé

La première ligne donne souvent le nombre de lignes qui suivent. Une boucle les lit.

Entrée

3
12
7
5

Programme

n = int(input())          # 3 : trois lignes suivent
total = 0
for _ in range(n):
    valeur = int(input())  # 12, puis 7, puis 5
    total = total + valeur
print(total)               # 24

5. Afficher : print()

  • Chaque print() écrit une ligne.
  • La comparaison est exacte, caractère par caractère. N'ajoutez aucun texte autour du résultat : print("Résultat :", aire) échoue là où print(aire) passe.
  • Les espaces et les majuscules comptent. Dans les tableaux, un point · marque chaque espace.
  • print(a, b) sépare les deux valeurs par une espace.
  • 24 et 24.0 sont deux sorties différentes. La division / rend un décimal ; // ou int() rendent un entier.
  • Le texte placé dans input("…") n'est pas affiché ici. Inutile d'en écrire.
  • Les lignes vides en fin de sortie ne comptent pas.

6. Messages d'erreur fréquents

Message ou symptômeCause
EOFError : plus aucune ligne à lire Le programme appelle input() plus souvent qu'il n'y a de lignes.
ValueError: invalid literal for int() int() reçoit une ligne qui n'est pas un entier seul, par exemple 6 4 ou 2.5. Découpez avec split(), ou convertissez avec float().
TypeError: can only concatenate str Un texte et un nombre sont additionnés : il manque int() à la lecture.
Sortie 64 au lieu de 10 Deux textes sont mis bout à bout : "6" + "4". Il manque int() à la lecture.
Sortie 24.0 au lieu de 24 Le calcul passe par / ou float(). Utilisez // ou int().
