Le mode arène

Un exercice, un groupe, un chrono commun, un classement

Une arène réunit un groupe sur le même exercice, avec un chrono commun. Chaque participant soumet sa solution une fois. Le classement se fait sur les tests réussis, puis sur le temps.

L'arène fonctionne sur les trois parcours du Codex : Python, SQL et R. Un enseignant la lance pour une séance. Des étudiants la lancent entre eux pour s'entraîner.

L'arène reste ouverte après la première manche. Le lanceur enchaîne d'autres exercices avec le même code et les mêmes participants.

Lancer une arène

  1. Ouvrez un exercice : choisi dans la liste, ou tiré au hasard avec les filtres.
  2. Cliquez sur ⚔️ Lancer une arène, sous l'énoncé.
  3. Réglez la durée. Elle est préremplie avec la durée conseillée de l'exercice.
  4. Entrez un pseudo. L'adresse @etu.unilasalle.fr est demandée si vous jouez vous-même en évaluation.
  5. Deux cases sont cochées par défaut : Je participe aussi et Je garde l'accès aux indices et aux solutions. Un enseignant qui ne joue pas décoche la première.
  6. Choisissez le mode : Évaluation, par défaut, ou Entraînement.

Le Codex affiche un code de six caractères en grand, pour le vidéoprojecteur, avec la liste de ceux qui ont rejoint. « 🔗 Lien » copie une adresse qui ouvre directement la fenêtre pour rejoindre. Le chrono démarre quand le lanceur clique sur Démarrer.

Aucun compte ni mot de passe n'est nécessaire.

Rejoindre une arène

  1. Ouvrez une page d'exercices du Codex : Python, SQL ou R. Si l'arène porte sur un autre langage, le Codex vous conduit sur sa page.
  2. Cliquez sur ⚔️ Rejoindre une arène, dans l'en-tête.
  3. Entrez le code de l'arène et un pseudo. Le pseudo s'affiche au classement.
  4. Entrez votre adresse @etu.unilasalle.fr. Elle est exigée en évaluation et facultative en entraînement. Seul le lanceur la voit.
  5. Dans une arène d'évaluation, choisissez En évaluation ou Hors évaluation. Le choix est définitif.

On peut rejoindre à tout moment, entre deux manches comme en cours de manche. Avant le départ, seul le lanceur connaît l'exercice.

Le déroulement d'une manche

  1. Le lanceur démarre. Un compte à rebours de dix secondes s'affiche sur tous les postes.
  2. Le même exercice s'ouvre partout, à partir du même point de départ : l'amorce en Python, la requête de départ en SQL, le code de départ en R.
  3. Pendant la manche, ceux qui ont rejoint n'ont ni indice ni solution. La liste des exercices, les filtres et le retour à l'accueil sont inaccessibles.
  4. « Tout tester » reste disponible pour vérifier son travail. Il ne compte pas.
  5. Soumettre joue les tests une dernière fois et envoie le code. La soumission est unique et définitive.
  6. À la fin du temps, le code de ceux qui n'ont pas soumis est remis de lui-même au lanceur. Il vaut 0 à la note et ne compte pas comme une réussite.

Le lanceur peut mettre le chrono en pause, le reprendre, et le prolonger d'une ou deux minutes. Les pauses ne comptent pas dans les temps. Une prolongation rouvre la soumission de ceux dont le code avait été remis automatiquement.

Un exercice est réussi quand tous ses tests passent.

Dans une arène d'évaluation, un participant peut choisir Hors évaluation. Il joue alors sans plein écran ni note, et retrouve indices et solution après sa soumission.

Note et médaille, en évaluation

  • Tous les exercices de l'arène sont du même niveau. Le serveur refuse une relance sur un autre niveau.
  • Chaque manche donne le pourcentage de tests réussis. La note sur 20 est la moyenne de ces pourcentages sur les manches closes.
  • Une manche sans soumission, avec une remise automatique ou avec une soumission non comptée vaut 0.
  • La manche en cours n'entre dans la moyenne d'un participant qu'une fois qu'il a soumis.
  • La médaille n'est attribuée qu'après une heure d'exercices cumulée sur l'arène, prolongations comprises. Avant, le podium et le bilan indiquent les minutes manquantes.

Fin de manche et manches suivantes

  • Le lanceur voit le podium en grand. Le classement suit le taux de tests réussis, puis le temps. Ceux qui n'ont rien soumis sont classés en dernier.
  • Chaque participant voit un bilan personnel.
  • Pour la manche suivante, le lanceur ouvre un autre exercice et clique sur ⚔️ Relancer l'arène sur cet exercice. Le code et les participants restent les mêmes.
  • 📋 Solutions montre au lanceur le code soumis par chacun, avec son adresse. Le lanceur y accorde ou retire les points d'une sortie du plein écran, et peut exclure un participant.
  • Deux exports couvrent toutes les manches : un fichier Markdown lisible et un fichier JSON brut.
  • Après une heure d'exercices en évaluation, ⤓ Fichier pour l'application produit un classeur au format d'import de l'application SkillQuest : une ligne par participant en évaluation avec son adresse, la compétence, l'XP de la médaille, la date, l'heure et la note.

Le lanceur qui quitte l'arène perd l'accès aux solutions et aux exports. Il exporte d'abord.

Une arène est liée à son langage. Rejointe depuis une autre page, elle s'ouvre sur la page de son langage. Ce changement de page n'est pas compté comme une sortie du plein écran.

Données et limites

  • Le serveur conserve l'exercice, la durée, le mode, les pseudos, les adresses, les sorties du plein écran et les codes soumis. L'arène s'efface au bout de 24 heures.
  • Le pseudo est visible de tous les participants. L'adresse n'est visible que du lanceur.
  • Les temps sont mesurés sur l'horloge du serveur.
  • Les tests sont joués par le navigateur du participant. Le serveur ne les rejoue pas.
  • Le navigateur ne permet ni d'imposer ni de retenir le plein écran. Une sortie est seulement constatée.
  • L'arène sert à l'entraînement et aux séances. L'évaluation certificative reste sur SEB.

Questions fréquentes

Je recharge la page pendant une manche.

L'arène reprend avec le dernier code testé. En évaluation, le rechargement compte comme une sortie du plein écran. Fermer l'onglet fait oublier l'arène au navigateur.

J'ai quitté l'arène et je reviens.

Rejoignez avec la même adresse : votre état est repris, soumission comprise. Un second pseudo ne donne pas une seconde soumission.

J'arrive en cours de manche.

L'exercice s'ouvre au point de départ, avec le temps restant.

Le code est refusé.

Le code compte six caractères, sans la lettre O ni la lettre I. Une arène s'efface 24 heures après sa création.

Le lanceur m'a exclu.

Le pseudo et l'adresse exclus ne peuvent plus rejoindre cette arène.
